# 합성데이터 오류 설계

## 1. 문서 목적

합성 데이터에 어떤 품질 문제를 어떤 이유로 어느 정도 포함했는지 기록한다. 행별 오류 위치는 기록하지 않으며, 생성 완료 후 계획 비율과 실제 생성 건수를 함께 남긴다.

## 2. 프로젝트 데이터 흐름

1. 센서 합성 데이터와 작업일지 합성 데이터 생성
2. 센서와 작업일지 통합
3. 통합 합성 데이터 전처리
4. 전처리 전후 품질 지표와 분포 비교

별도의 정답 데이터와 오류 위치별 manifest는 만들지 않는다. 생성 코드와 랜덤 시드는 보존해 같은 조건의 데이터를 다시 만들 수 있도록 한다.

## 3. 오류 설계 원칙

- 원본 센서의 정상·불량 및 12개 결함 유형 분포를 최대한 유지한다.
- 센서별 범위와 5초 시퀀스의 형태를 심하게 훼손하지 않는다.
- 전처리 방법별 효과를 수치와 그래프로 확인할 수 있을 만큼만 문제를 넣는다.
- 하나의 샘플에 너무 많은 문제가 겹치지 않도록 주입 대상을 제어한다.
- 정상·불량 라벨과 결함 유형 라벨은 변경하지 않는다.
- 작업 중 `operation` 일지에는 최종 결함명이나 정답을 노출하지 않는다.
- 검사 후 `post_inspection` 품질일지에는 정상·불량과 결함명을 포함하고, 전처리 단계에서 모델 입력 대상에서 제거한다.

## 4. 정형·시계열 품질 문제

| 품질 문제 | 주입 단위 | 권장 계획 비율 | 15,132개 기준 예상 규모 | 주입 근거 | 전처리 확인 지표 |
|---|---|---:|---:|---|---|
| 센서값 결측 | 샘플 | 3.0% | 약 454개 샘플 | 센서 수집 누락과 통신 지연 상황을 표현 | 컬럼별 결측률, 결측 패턴, 대체 전후 분포 |
| 센서 스파이크·이상치 | 샘플 | 1.0% | 약 151개 샘플 | 순간적인 측정 오류와 비정상 급변을 표현 | IQR·강건 z점수 후보 수, 처리 전후 꼬리 분포 |
| 전체 샘플 중복 | 샘플 | 0.5% | 약 76개 중복 | 수집·통합 과정의 재적재 상황을 표현 | 중복 sample 수와 제거 후 행 수 |
| 샘플 내부 측정행 중복 | 샘플 | 1.0% | 약 151개 샘플 | 센서 메시지 재수신 상황을 표현 | sample별 timestamp 중복 수 |

센서 결측은 선택한 샘플의 25개 센서 셀 전체를 비우지 않고 1~2개 측정값에만 적용한다. 이상치는 실제 불량값을 무조건 오류로 간주하지 않도록, 원래 분포의 상·하한과 시계열 변화량을 기준으로 통제해서 만든다.

## 5. 작업일지 품질 문제

| 품질 문제 | 주입 단위 | 권장 계획 비율 | 주입 근거 | 전처리 확인 지표 |
|---|---|---:|---|---|
| 작업일지 결측 | 기대되는 로그 연결 | 5.0% | 수기 누락과 미작성 상황 표현 | 미연결 샘플률, 결측 텍스트 수 |
| 작업일지 중복 | 로그 | 2.0% | 복사 입력과 중복 등록 상황 표현 | 완전·유사 중복 로그 수 |
| 약어 사용 | 비결측 로그 | 15.0% | 현장 축약어 사용 표현 | 표준화 전후 용어 빈도 |
| 불규칙한 띄어쓰기 | 비결측 로그 | 7.0% | 수기 입력의 표기 차이 표현 | 공백 정규화 전후 고유 문장 수 |
| 오탈자 | 비결측 로그 | 3.0% | 빠른 현장 입력의 오타 표현 | 교정 대상 수와 어휘 변화 |
| 설비명 표기 차이 | 비결측 로그 | 5.0% | 동일 설비의 여러 표기 표현 | 표준화 전후 설비명 종류 수 |

텍스트 문제는 서로 일부 겹칠 수 있다. 한 문장에 오류가 과도하게 집중되지 않도록 로그당 최대 문제 수를 제한한다.

## 6. 센서와 작업일지 연결 문제

| 품질 문제 | 주입 단위 | 권장 계획 비율 | 15,132개 기준 예상 규모 | 주입 근거 | 전처리 확인 지표 |
|---|---|---:|---:|---|---|
| 시각 또는 설비 연결 불일치 | 로그가 연결된 샘플 | 1.0% | 약 151개 샘플 | 수기 시각 오차와 설비 선택 오류 표현 | 시간 범위 밖 연결, 설비키 불일치, 수정 후 연결률 |

교대 로그 하나가 여러 센서 샘플에 연결되는 일대다 관계는 오류가 아니라 정상적인 데이터 구조로 취급한다.

## 7. 제외한 문제

다음 문제는 과제 범위에서 제외한다.

- 숫자를 문자열로 변환하거나 단위를 값에 섞는 문제
- 날짜·시각 형식을 여러 형태로 섞는 문제
- 정상·불량 라벨 반전
- 결함 유형 오표기
- 작업 중 `operation` 일지에 최종 결함명을 직접 기록하는 방식

## 8. 생성 후 기록할 항목

데이터를 생성한 뒤 이 문서에 다음 결과를 추가한다.

1. 사용한 랜덤 시드
2. 생성 전후 총 샘플과 센서 측정행 수
3. 각 문제의 계획 비율과 실제 생성 건수·비율
4. 문제 간 중복 적용 건수
5. 정상·불량 및 결함 유형별 분포 변화
6. 센서별 평균·표준편차·분위수 변화
7. 생성 과정에서 계획과 다르게 조정한 내용과 이유
