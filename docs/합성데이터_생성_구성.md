# 합성데이터 생성 구성

## 1. 생성 목적

원본 SMT 센서 데이터는 결측과 중복이 거의 없는 정제 데이터이므로 전처리 효과를 확인하기 어렵다. 이에 원본의 센서 분포와 5초 시퀀스를 보존한 반합성 센서 데이터와 한국어 작업일지를 만들고, 계획된 품질 문제를 추가했다. 별도의 정답 데이터와 오류 위치별 manifest는 만들지 않았다. 생성 코드와 랜덤 시드 42를 이용해 같은 결과를 재현할 수 있다.

## 2. 표본과 분할

원본 27,830개 중 15,132개 시퀀스를 정상·불량, 결함 유형, 원본 A~D 코드 비율을 고려해 층화 추출했다. 원래 Training에서 학습 12,106개와 검증 1,513개를, 원래 Validation에서 테스트 1,513개를 뽑았다. 비율은 약 80.003%:9.999%:9.999%다. 한 원본 시퀀스는 하나의 분할에만 사용했다.

## 3. 센서 데이터 구성

샘플 하나는 1초 간격 센서 측정 5행으로 구성된다. 컬럼은 온도, 습도, 진동, 가속도, 소음이다. 원본 시퀀스 전체에 학습 데이터 표준편차의 3% 이내 오프셋과 행별 1% 이내 잡음을 더한 뒤 원본 범위로 제한했다. 원본과 반합성 데이터의 센서별 표준편차 비율은 0.9988~1.0002였고, 센서 상관계수의 최대 차이는 0.00086이었다.

각 샘플에는 `sample_id`, `equipment_id`, `lot_id`, `shift_date`, `shift_code`를 부여했다. `sample_id`는 5개 측정행을 묶고, `equipment_id`와 `lot_id`는 작업일지 연결에 사용한다. 교대는 08~20시 주간조와 나머지 야간조로 구성했다. 원본 A~D 코드는 의미가 확인되지 않아 생성 과정의 층화 기준으로만 사용하고 결과 파일에서는 제외했다.

## 4. 작업일지 구성

오류 주입 전 작업일지는 1,085건이었다. 교대 시작점검·인수인계 116건, 로트별 생산실적 533건, 센서 변동에 따른 이상점검 303건, 검사 후 품질일지 133건으로 만들었다. 작업 당시 기록은 `record_stage=operation`, 검사 완료 후 기록은 `post_inspection`으로 구분했다.

`operation` 일지는 당시 확인할 수 있는 센서 변화와 조치만 포함한다. `post_inspection` 일지는 실제 품질기록을 표현하기 위해 정상·불량과 세부 결함명을 포함한다. 최종 파일에서 정답 표현이 포함된 검사 후 일지는 129건이다. 전처리 단계에서는 데이터 누수를 막기 위해 `post_inspection` 행을 모델 입력 대상에서 제거한다.

## 5. 주입한 품질 문제

센서에는 결측 샘플 454개와 결측 셀 548개, 스파이크 151개, 전체 샘플 중복 76개, 샘플 내부 측정행 중복 151개를 넣었다. 이에 따라 15,132개 기본 샘플·75,660행이 전처리 전 파일에서는 15,208개 `sample_id`·76,191행으로 증가했다.

작업일지에는 미작성 로그 33건, 텍스트가 빈 로그 22건, 완전 중복 10건, 내용 중복 11건을 넣었다. 텍스트에는 약어 154건, 불규칙한 띄어쓰기 72건, 오탈자 31건, 설비명 표기 차이 52건을 적용했다. 연결 문제는 시각 불일치 76건과 설비 불일치 75건을 만들었다. 시각 불일치 로그 한 건이 중복되어 최종 파일에서는 시간 범위를 벗어난 행이 77개로 관찰된다. 최종 작업일지는 1,073행이다.

## 6. 산출물과 검증

- `data/interim/synthetic_sensor_dirty.parquet`: 76,191행, 16열
- `data/interim/synthetic_worklog_dirty.parquet`: 1,073행, 16열
- `scripts/01_generate_synthetic_data.py`: 생성·오류 주입·검증 코드

저장 후 파일을 다시 읽어 자료형과 행 수를 확인했다. 분할 사이 `sample_id`, `lot_id`, `log_id`의 교차 사용은 0건이었다. 작업 중 일지에서 정상·불량 및 결함명 노출은 0건이고 검사 후 일지에서만 확인됐다. 센서와 연결되는 모든 작업일지의 `lot_id`가 존재하는 것도 확인했다.
